## 📡 REST & SSE Endpoints Matrix

- `GET /api/status`: System state, Darwin Mach RAM headroom, active model, and training telemetry.
- `GET /api/stream`: Sub-millisecond Server-Sent Events (SSE) feed delivering live battle ticks, HP drains, and DPO pairs.
- `GET /api/ecommerce/status`: 365-day store simulation metrics, liquid asset balance, and live GraphQL mutation log.
- `POST /api/ecommerce/step`: Advance store simulation by 1 or N days.
- `POST /api/ecommerce/reset`: Reset store simulation to Day 1 with $15,000 initial capital.
- `GET /api/roi/games`: Dynamic ROI leaderboard ranking all training tracks and CodeClash.ai games.
- `POST /api/games/run_match`: Trigger real-time head-to-head battle on specified track.
- `GET /api/leaderboard/all`: Meritocratic 15-role project leaderboard assigning canonical roles to top models.
