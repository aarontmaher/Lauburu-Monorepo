# Movesense HR+ TinyML & Reverse Engineering Specification

## 1. Hardware Overview & Memory Constraints
The Movesense HR+ wearable is powered by the **Nordic Semiconductor nRF52832** SoC (ARM Cortex-M4F). 

### Memory Limits
- **Total On-Chip Flash:** 512 KB
- **Total On-Chip RAM:** 64 KB
- **External EEPROM:** 384 KB (3 Mbit) - Primarily used for data logging via Movesense DataLogger, not for executable code or runtime heap.

**Available Space for Custom Applications:**
The Movesense OS (Whiteboard API, BLE SoftDevice, Sensor drivers, etc.) consumes a significant portion of this memory.
- **Available RAM:** ~15 KB - 25 KB for user applications (Stack + Heap).
- **Available Flash:** ~200 KB - 250 KB for user application code and constant data (like model weights).

> [!WARNING]
> Because RAM is strictly limited to around ~20KB, any TinyML framework and its associated tensor arena (working memory) must be highly optimized.

## 2. TinyML Framework Selection

Given the < 20KB RAM constraint, the following frameworks are viable:

1. **TensorFlow Lite for Microcontrollers (TFLM):** 
   - **Pros:** Industry standard, huge community, supports int8 quantization natively.
   - **Cons:** Framework overhead (OpResolver, interpreter) takes some RAM/Flash. You must restrict the `MicroMutableOpResolver` to load only the specific operations you use to save flash.
2. **Edge Impulse:**
   - **Pros:** Excellent native support for Nordic nRF52 series. Auto-generates C++ code leveraging ARM CMSIS-NN optimizations. 
   - **Cons:** Abstracts away some lower-level control, but typically provides the smallest footprint vs vanilla TFLM.
3. **Pure C/C++ Array (CMSIS-NN):**
   - **Pros:** Absolute minimum footprint. Zero framework overhead.
   - **Cons:** Hardest to implement, requires manual weight extraction and function calls.

**Recommendation:** For standard deep learning (1D CNN or MLP), **TFLM** (or Edge Impulse's wrapped version of it) is optimal if you aggressively quantize to `int8` and limit the tensor arena to < 10KB.

## 3. TensorFlow Lite for Microcontrollers (TFLM) Integration Guide

### Step 1: Model Preparation
1. Train a 1D CNN or small MLP using Keras/TensorFlow. Keep parameter count under 10,000.
2. Convert to `.tflite` using TFLiteConverter with **full integer (int8) quantization**. Provide a representative dataset of ECG samples to calibrate the quantization.
3. Convert the `.tflite` file to a C-byte array using `xxd -i model.tflite > model_data.cc`.

### Step 2: Movesense Integration
Movesense uses a component-based Whiteboard API (`wb::api`). You subscribe to sensor data paths (e.g., `/Meas/ECG/512` for 512 Hz ECG) and receive callbacks. The inference loop should run on the incoming buffers.

### C++ Implementation Stub

Below is a C++ stub demonstrating how to initialize TFLM and hook it into the Movesense ECG 512Hz datastream.

```cpp
#pragma once

#include <whiteboard/LaunchableModule.h>
#include <whiteboard/ResourceClient.h>
#include <meas_ecg/resources.h> // Movesense ECG API

// TFLM Includes
#include "tensorflow/lite/micro/all_ops_resolver.h"
#include "tensorflow/lite/micro/micro_error_reporter.h"
#include "tensorflow/lite/micro/micro_interpreter.h"
#include "tensorflow/lite/schema/schema_generated.h"
#include "tensorflow/lite/version.h"

// Your model array (generated by xxd)
extern const unsigned char g_model[];

class TFLiteEcgComponent : public wb::ResourceClient, public wb::LaunchableModule {
private:
    // TFLM Globals
    tflite::ErrorReporter* error_reporter;
    const tflite::Model* model;
    tflite::MicroInterpreter* interpreter;
    TfLiteTensor* input;
    TfLiteTensor* output;
    
    // Allocate 8KB for tensor arena. Adjust based on model requirements.
    static constexpr int kTensorArenaSize = 8 * 1024; 
    uint8_t tensor_arena[kTensorArenaSize];

    // Buffer for 512Hz ECG window (e.g., 1 second window = 512 samples)
    static constexpr int kWindowSize = 512;
    float ecg_buffer[kWindowSize];
    int buffer_idx = 0;

public:
    TFLiteEcgComponent() : ResourceClient(), LaunchableModule(), error_reporter(nullptr), model(nullptr), interpreter(nullptr), input(nullptr), output(nullptr) {}

    virtual bool initModule() override {
        // 1. Initialize TFLM
        static tflite::MicroErrorReporter micro_error_reporter;
        error_reporter = &micro_error_reporter;

        model = tflite::GetModel(g_model);
        if (model->version() != TFLITE_SCHEMA_VERSION) {
            // Handle error
            return false;
        }

        // Use MicroMutableOpResolver in production to save flash memory
        static tflite::AllOpsResolver resolver;
        static tflite::MicroInterpreter static_interpreter(
            model, resolver, tensor_arena, kTensorArenaSize, error_reporter);
        interpreter = &static_interpreter;

        TfLiteStatus allocate_status = interpreter->AllocateTensors();
        if (allocate_status != kTfLiteOk) return false;

        input = interpreter->input(0);
        output = interpreter->output(0);

        // 2. Subscribe to 512Hz ECG stream
        wb::Result result = asyncSubscribe(WB_RES::LOCAL::MEAS_ECG_512());
        return (result == wb::HTTP_CODE_OK);
    }

    virtual void deinitModule() override {
        asyncUnsubscribe(WB_RES::LOCAL::MEAS_ECG_512());
    }

    // Movesense callback for incoming data
    virtual void onNotify(wb::ResourceId resourceId, const wb::Value& value, const wb::ParameterList& parameters) override {
        if (resourceId.localResourceId == WB_RES::LOCAL::MEAS_ECG_512::LID) {
            const WB_RES::ECGData& ecgData = value.convertTo<const WB_RES::ECGData&>();
            
            // Process incoming samples
            for (size_t i = 0; i < ecgData.samples.size(); ++i) {
                ecg_buffer[buffer_idx++] = static_cast<float>(ecgData.samples[i]);
                
                // When we have a full window, run inference
                if (buffer_idx >= kWindowSize) {
                    runInference();
                    buffer_idx = 0; // Reset or slide window
                }
            }
        }
    }

private:
    void runInference() {
        // Copy data into model input tensor
        // Note: If using int8 model, you must quantize the float data here first
        for (int i = 0; i < kWindowSize; i++) {
            input->data.f[i] = ecg_buffer[i]; // Assuming float model for simplicity
        }

        // Invoke TFLM
        TfLiteStatus invoke_status = interpreter->Invoke();
        if (invoke_status != kTfLiteOk) {
            // Handle error
            return;
        }

        // Process output (e.g. classification result)
        float result = output->data.f[0];
        // Action on result: trigger ble notification, save to EEPROM, etc.
    }
};
```

> [!TIP]
> The above stub uses float operations for simplicity. In a strictly RAM-constrained nRF52832, you **must** use an `int8` quantized model. This means you will need to map the raw integer `ECGData.samples` directly into the `input->data.int8` tensor using the `scale` and `zero_point` parameters of your quantized input layer.
