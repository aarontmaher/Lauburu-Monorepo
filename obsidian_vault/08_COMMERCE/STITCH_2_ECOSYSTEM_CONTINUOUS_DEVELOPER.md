## 🛡️ 3. Cardinal Law #1 Zero-Mock Data & Backend Binding Protocol

Per explicit user directive: **"don't use mock data just flag when back end data is needed and we can develop it"**.

### Enforcement Heuristics:
1. **Zero-Synthetic Arrays:** Hardcoded mock arrays, fake timers, and simulated graphs are strictly prohibited.
2. **Clean Waiting States:** Any telemetry stream awaiting live sensor pairing or background connection displays clean waiting badges:
   - `[STATUS: Awaiting Movesense BLE 512Hz — Connect via GATT 0x180D]`
   - `[STATUS: Awaiting Google Workspace OAuth — Bind via Port 5050]`
   - `[STATUS: Awaiting Live Wi-Fi 7 RTSP Stream — Camera on Pixel Node L6]`
3. **Explicit Backend Dependency Contract:** All unlinked backend requirements are programmatically registered in [`08_business_and_commerce/stitch2_backend_dependencies.json`](file:///Volumes/Lauburu-Monorepo/08_business_and_commerce/stitch2_backend_dependencies.json).
