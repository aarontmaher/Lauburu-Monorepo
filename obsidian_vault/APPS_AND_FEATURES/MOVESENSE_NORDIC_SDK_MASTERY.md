# Movesense & Nordic SDK Mastery: TinyML & ECG Analytics

## 1. SDK Architecture & Interoperability
The Movesense sensor is powered by the Nordic nRF52832 SoC. Developing for this platform involves understanding the distinct SDK ecosystems:

*   **Movesense SDK:** This is the mandatory, proprietary framework for building custom firmware on Movesense sensors. It exposes a specialized C++ Whiteboard API for the sensor's IMU, ECG, and BLE constraints. Crucially, it is historically built upon the older **nRF5 SDK and FreeRTOS**, utilizing a Dockerized CMake build environment.
*   **nRF Connect SDK (NCS):** Nordic’s modern, Zephyr-based development platform. While Nordic transitioned to NCS, Movesense did not. You cannot natively compile NCS Zephyr modules inside a Movesense firmware project. 
*   **Nordic Edge AI Add-on:** A specialized machine learning extension provided by Nordic. Because it is designed strictly as an add-on for the Zephyr-based NCS, it **cannot** be easily integrated into standard Movesense SDK projects.
*   **Interoperability:** The primary integration point is Over-the-Air (OTA) updates. Movesense firmware utilizes standard Nordic DFU (Device Firmware Update) bootloader protocols, allowing compiled Movesense binaries to be flashed using standard Nordic BLE tools (like nRF Connect for Mobile).

## 2. Edge AI & TinyML Integration (Edge Impulse)
Because the Nordic Edge AI Add-on is incompatible with the Movesense SDK, developers must rely on **Edge Impulse**.

1.  **Data Ingestion:** The Movesense sensor operates at up to 512 Hz for single-lead ECG data, providing the required resolution (minimum artifact rate) for HRV and DFA-alpha1 analytics.
2.  **Edge Impulse Pipeline:** 
    *   Raw data is ingested into Edge Impulse Studio.
    *   **HR/HRV Blocks** extract clean RR intervals from the ECG stream.
    *   **1D CNN Blocks** provide spatial-temporal feature extraction to classify arrhythmias or movement states.
    *   The model is exported as a **framework-agnostic C++ library**, which can be dropped directly into the Movesense SDK's CMake/Docker toolchain.
3.  **DFA-alpha1 Constraints:** Edge Impulse provides the RR interval array, but DFA-alpha1 is a non-linear regression metric for aerobic threshold estimation. The actual detrended fluctuation calculation is typically implemented as a custom C++ mathematical function directly within the Movesense node firmware, processing the outputs generated by the Edge Impulse extraction block.
