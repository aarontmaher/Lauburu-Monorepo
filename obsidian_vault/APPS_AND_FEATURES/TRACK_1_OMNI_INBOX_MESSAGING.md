## 🛠️ 3. Concrete Implementation Plan

### A. Data Models (`lib/models/inbox_models.dart`)
- `InboxChannel`: `gmail_personal`, `gmail_business`, `sms`, `instagram`, `facebook`, `shopify`, `gumtree`
- `InboxPriority`: `action_required`, `commercial_offer`, `vip`, `low_priority`
- `InboxConversation`: Contact name, avatar URL, channel badge, last message preview, unread count, timestamp.
- `InboxMessage`: ID, sender ID, text content, timestamp, incoming/outgoing flag, AI suggested replies array.

### B. User Interface (`lib/screens/omni_inbox_screen.dart`)
1. **Top Segmented Filter Bar:**
   - `[All Messages]`, `[Gmail: Personal]`, `[Gmail: Lauburu]`, `[Instagram]`, `[SMS]`, `[Shopify]`
2. **Conversation List View:**
   - Visual badges with platform colors:
     - Gmail: Red/Blue
     - Instagram: Purple/Pink gradient
     - SMS: Emerald Green
     - Shopify: Charcoal/Bright Green
   - Priority indicator dots (Orange = Action Required, Gold = Commercial Lead).
3. **Thread / Message View:**
   - Left-aligned bubbles for contacts, right-aligned bubbles for Aaron.
   - **Local AI Smart Reply Bar:** Floating action chips generated by `Qwen 3.8 Max` on Port 8082 (e.g. *"Sounds good, pick up at Altona Gate"*, *"Tracking link sent"*).
   - Voice Dictation button wired to dynamic ambient mic stream.
