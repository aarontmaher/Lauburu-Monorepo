### 1. The 4 Massive Advantages of Pure NPU Sharding

1. **Zero Metal GPU Contention (100% Host Graphics Headroom):**
   - The Mac Mini's 20-core Metal GPU is completely freed for display rendering, 120Hz window compositing, and large LLM language generation. 
   - Screen Lens visual perception no longer steals unified memory bandwidth from your primary coding models.
2. **Thermal & Power Plunge (5× to 10× More Efficient):**
   - **On the Pixel:** Running a vision model on the mobile GPU draws ~4.2 W, quickly warming the phone to >40°C and triggering thermal throttling. Running on the **Edge TPU draws ~0.6 W**. The phone remains at its audited **27.7°C** indefinitely.
   - **On the Mac:** The Apple Neural Engine consumes a fraction of the power of the Metal GPU for INT8/FP16 matrix math.
3. **Bandwidth Preservation (The SRAM Advantage):**
   - Both the ANE and Edge TPU have dedicated on-chip high-speed SRAM caches. High-resolution 1920×1080 pixel convolutions are computed in local NPU SRAM, bypassing the main LPDDR5X RAM bus and leaving all **273 GB/s** of memory bandwidth available for LLM token decoding.
4. **Sub-20ms Reactive Visual Latency:**
   - Instead of transmitting full-resolution PNG/base64 frames across the network, the Pixel Edge TPU prunes 90% of blank pixels and sends only **salience graph embeddings** over the Gigabit wire (<1ms transfer time).

### 2. The Hard Technical Trade-Offs (Reality Check)

1. **Format Lock-in (GGUF Does NOT Run on NPU):**
   - `llama.cpp` and GGUF do **not** target Apple Neural Engine or Google Edge TPU—they target CPU, Metal, and Vulkan/OpenCL.
   - **Requirement:** To run strictly on NPU, models must be exported to **CoreML** (`.mlpackage`) on macOS and **TFLite / LiteRT INT8** (`.tflite` with Edge TPU delegate) on Android.
2. **Static Tensor Shapes:**
   - NPUs achieve extreme TOPS/Watt because their computational graphs are compiled ahead-of-time (AOT) with fixed tensor shapes (e.g., fixed $384 \times 384$ or $512 \times 512$ image patches). Dynamic image resolutions must be padded or tile-cropped to fixed dimensions.
3. **Autoregressive Text Generation Penalty:**
   - NPUs excel at **parallel matrix multiplication** (Vision Encoders, CNNs, ViT patch projection, and AST embeddings).
   - They are *less* efficient at autoregressive sequential token decoding (generating long text one token at a time).
   - **Optimal Architecture:** Run the **Vision Encoder & Action Salience Graph on the NPU**, and let the **Language Decoder run on the CPU/Metal GPU**.
