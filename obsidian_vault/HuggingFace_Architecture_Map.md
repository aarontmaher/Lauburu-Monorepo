# 🤗 Hugging Face Ecosystem Integration Map

This document tracks where each component of the Hugging Face Tri-Orchestrator integration resides within the Lauburu Monorepo structure, detailing its exact architectural purpose.

## 1. `smolagents` 
**Monorepo Location:** `05_agents_and_swarms/`
- **Purpose:** Acts as the dynamic multi-agent routing fabric and core execution engine.
- **Integration Detail:** Replaces brittle ad-hoc prompt chains with robust tool-calling pipelines. It is the primary interceptor for the Zero-Cloud Failover—dynamically catching Cloud Inference API exhaustion (Error 402) and instantly routing the workload to local mesh hardware (`llama.cpp` / Thunderbolt mesh) via the decoupled async bridge.

## 2. `TRL` (Transformers Reinforcement Learning)
**Monorepo Location:** `12_continuous_lora_evolution/`
- **Purpose:** Drives the offline, continuous learning pipeline.
- **Integration Detail:** Executes overnight Teacher-Student Distillation and Direct Preference Optimization (DPO). It takes the high-quality trajectories previously generated by the Cloud AI (when credits were available) and uses them to mathematically align and fine-tune our local offline models (applying LoRA weights) to improve their capability over time without increasing cloud spend.

## 3. `datasets`
**Monorepo Location:** `04_data_and_memory/`
- **Purpose:** Manages high-speed, local data serialization.
- **Integration Detail:** Replaces standard JSON/SQLite trajectory logging with Arrow-backed, memory-mapped caching. This allows the local mesh to stream and sample massive agent instruction sets across devices with sub-microsecond latency and zero memory overhead, directly feeding the `TRL` distillation engine.

## 4. `evaluate`
**Monorepo Location:** `02_ai_models_and_inference/`
- **Purpose:** Swarm capability benchmarking and ELO tracking.
- **Integration Detail:** Functions as the objective mathematical quality gate. Before a task is routed to the local mesh by `smolagents`, `evaluate` checks the ELO and confidence score of the local model for that specific task type to ensure accuracy doesn't degrade when falling back from the Cloud.

## 5. Async Decoupled Bridge (In-Process Bounded Queue)
**Monorepo Location:** `00_core_infrastructure/`
- **Purpose:** The high-speed connective tissue.
- **Integration Detail:** Connects the `localhost:3000` main training loops to the Python-based Hugging Face backend. Designed for sub-microsecond dispatch to ensure the main training pipeline is never blocked, even during heavy local LoRA distillation or local LLM execution.
