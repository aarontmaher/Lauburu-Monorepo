## 2. Logic Chain

1. **Root Cause Identification**:
   - `autonomous_consensus_merger.py` (`_register_offspring_in_leaderboard`) is responsible for registering dynamically merged models into `data/canonical_ai_leaderboard.json`.
   - When building the registered model dictionary (`new_entry`), it only sets 12 keys, omitting 12 keys mandated by `CANONICAL_LEADERBOARD_SCHEMA_V7`.
   - It also writes to disk via plain `json.dump()` without executing `validate_ledger_schema()` or `atomic_save_canonical_ledger()`.

2. **Propagation to Other Test Suites**:
   - Because `data/canonical_ai_leaderboard.json` is a shared monorepo state file, executing `test_milestone2_lora_harvesting_and_metal_training.py` or running the merge engine mutates `data/canonical_ai_leaderboard.json` with schema-invalid items.
   - Any subsequent test (such as `tests/e2e/test_continuous_ai_arena_tier5_adversarial.py`) that reads `data/canonical_ai_leaderboard.json` and invokes `record_match_victory()` fails when `atomic_save_canonical_ledger()` enforces JSON Schema v7 validation.

3. **Required Invariants for Clean Pass**:
   - All offspring entries registered in `leaderboard` and `fighters` must satisfy `CANONICAL_LEADERBOARD_SCHEMA_V7` / `ModelEntry`.
   - Specialist skills must be populated as a dictionary of `{"skill_name": score_float}` blending parents' skills with a +0.5 consensus bonus.
   - `project_contribution_elo` must be calculated as `round(0.60 * offspring_elo + 0.40 * (canonical_score * 20.0), 1)`.
   - Existing corrupted entries currently present on disk in `data/canonical_ai_leaderboard.json` must be purged/regenerated using `CanonicalAILeaderboardEngine.get_canonical_leaderboard(persist=True)`.

    def _write_canonical_leaderboard(self, data: Dict[str, Any]):
        """Writes canonical leaderboard with schema validation and atomic replace."""
        data["last_updated_utc"] = time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime())
        data["last_updated"] = data["last_updated_utc"]
        
        # Try using self_healing_hub atomic_save_canonical_ledger if available
        try:
            hub_src = self.workspace_root / "00_core_infrastructure" / "self_healing_hub" / "src"
            if str(hub_src) not in sys.path:
                sys.path.insert(0, str(hub_src))
            from canonical_ai_leaderboard import atomic_save_canonical_ledger
            if "schema_version" in data and "benchmark_pillars" in data:
                atomic_save_canonical_ledger(data, self.leaderboard_file)
                return
        except Exception as e:
            logger.debug(f"Could not use atomic_save_canonical_ledger: {e}")
            
        # Fallback thread-safe atomic POSIX replace write
        self.leaderboard_file.parent.mkdir(parents=True, exist_ok=True)
        tmp_file = self.leaderboard_file.with_suffix(f".tmp.{os.getpid()}.{time.time_ns()}")
        try:
            with open(tmp_file, "w", encoding="utf-8") as f:
                json.dump(data, f, indent=2, ensure_ascii=False)
                f.flush()
                os.fsync(f.fileno())
            os.replace(tmp_file, self.leaderboard_file)
        finally:
            if tmp_file.exists():
                try:
                    tmp_file.unlink()
                except Exception:
                    pass
